# التنفيذ المرحلي المعتمد

| المرحلة | الأولوية والنتيجة المنشورة | ما لا يفتح قبل نجاحه |
|---|---|---|
| 1 | الرئيسية الفعلية بمفاتيح الصور الأربع، الهوية ومقاسات الجوال والتبديل والإتاحة وPWA والصفحات العامة، Worker+D1+DNS على idvip.app، checkpoint ونسخة GitHub | التسجيل والتحرير والمراجعة لا تتظاهر بالعمل في هذه المرحلة |
| 2 | حسابات متحققة ببريد Resend، الأدوار العليا، حجز المواقع، المحرر والمسودة والحفظ وطلب النشر والموافقة البسيطة والسجل، نطاقات المستخدمين | الرفع يتطلب تفعيل R2 الحقيقي، والبريد الاحتياطي يحتاج أهلية إرسال Cloudflare |
| 3 | العينة الكاملة والملفات المنشورة وQR وvCard وPDF A4/ATS مع لغة ووضع وحقوق إظهار صحيحة، بحث ومدونات وإشعارات | PDF لا يعلن كتنزيل حقيقي قبل اختبار ملفه؛ Push يحتاج إذناً واشتراكاً ومرسل WebPush حقيقي |
| 4 | التدقيق الأمني والحقوق والحذف والاحتفاظ والتصدير والاستعادة المقيدة، فحص مستقل وإصلاحات مثبتة ونقطة إطلاق جاهزة للاختبار | لا توصف الخدمة باعتماد قانوني أو حصانة مطلقة للسجل، ولا تفتح ميزة غير مكتملة |

لكل مرحلة تقرير موجز بنتائج فعليّة وSHA والنسخة المنشورة. إذن المالك مستمر بالانتقال ولا تعاد الموافقة على قراراته. أي طلب دفع أو إعداد لا يمكن تجاوزه يُصعّد فقط عند وجود حاجة حقيقية مع السعر والاختيار، وتستمر الأعمال المستقلة عنه.
