# مرحلة دمج الحسابات المدارة والمخرجات

اكتمل محرر العهدة الحقيقي الذي ينشئ حساباً وموقعاً قبل استلامهما دون انتحال جلسة، ويسقط تحكم العهدة عند OTP وقبول المستفيد. أُصلح انتظار حفظ المحرر قبل التنقل، وتثبيت معرف البريد المعلق، وفلاتر/صفحات الإدارة، وسجل الخروج والرفع. شمل الدمج صور العينة الست وvCard ذي الرابط الشخصي وATS النصي والوضعين، وواجهة Push الاختيارية.

النسخة اجتازت74اختباراً محلياً وفحص TypeScript وبناء Vite وdry-run Worker. في7نوفمبر2026عند01:20 بتوقيتالرياض طبقت الترحيلات0002و0003و0005 بعيداً علىD1 وأكدWrangler نجاحها؛ قاعدة المستخدمين الإنتاجية لم تملأ بحسابات اختبار. لا تعني هذه الخطوة أن Worker الجديد نُشر بعد، ولا تعني قبول بريد أو PDF أو Push حي.

R2 غير مفعل؛ صفحة الحساب تعرض0.00دولار فوراً وتجديداً شهرياً بلا رسمأساسي مع رسوم زيادة التخزين والعمليات وحدودها. البريد البديل يتطلبWorkers Paid ويحتاج مرسلاً موثقاً وربطاً أصلياً. لا تُتم أي صفقة أو بطاقة نيابة عن المالك. Push غير مفعل إنتاجياً حتى توفير VAPID ومراجعة endpoints الفعلية، والحملات الكبيرة ليست queueمستديماً في هذه المكملة.
